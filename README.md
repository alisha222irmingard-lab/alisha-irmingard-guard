## Что это

**Alisha Irmingard Guard** — готовый защитный Skill для Codex. Он проверяет внешние сайты, ссылки, репозитории GitHub, Skills, плагины, расширения и установщики **до** скачивания, запуска и выдачи доступа.

## Как пользоваться

1. Скачайте файл `alisha-irmingard-guard-v1.0.1.zip` из этого репозитория.
2. Распакуйте архив, сохранив внутреннюю структуру папок.
3. Установите папку как локальный плагин или Skill в Codex.
4. Отправьте ссылку и напишите: **«Проверь перед установкой»**.

## Понятный вердикт

- 🟢 **GREEN — МОЖНО:** явных опасных признаков не найдено.
- 🟡 **YELLOW — ОСТОРОЖНО:** есть неизвестные детали, лишние разрешения или риск.
- 🔴 **RED — НЕ СКАЧИВАЙТЕ И НЕ ЗАПУСКАЙТЕ:** найден опасный признак или источник нельзя подтвердить.

## Что внутри

- проверка точного домена и владельца;
- проверка установочных скриптов, зависимостей и внешних загрузок;
- поиск фишинга, поддельных зеркал, запросов паролей и лишних прав;
- готовый шаблон `AGENTS.md` для постоянной защиты.

Плагин не содержит внешнего сервера, платного API, телеметрии, авторизации и фоновых процессов.
